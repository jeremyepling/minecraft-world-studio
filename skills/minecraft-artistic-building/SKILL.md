# Artistic building

Start with the subject, site and one place the eye should land. Read the selected object's current intent, recipe and protected regions. For a new object, establish art direction when requested or when the player explicitly wants to match an established project. A nearby painted build alone gives no instruction to paint.

Design the silhouette and negative space from the approach the player will use. Set one dominant value mass, a quieter supporting region and a small accent. Describe a consequential choice in ordinary language. Ask a single question when the answer changes the result, such as whether an occupied gate should feel welcoming or threatening. Choose reversible defaults for the rest.

Assign the paint to semantic surfaces. Choose a material for its observed value, temperature, pattern scale and silhouette. Check shape, orientation, physics, light and interactions before substituting blocks. Use a deterministic field and a bounded material ramp. Native pixel texture often provides enough small detail. Keep cause and direction consistent across adjacent faces.

On a revision retrieve the previous design, change the requested parameters and compare the previous, proposed and live cells. Keep hand edits. Check that an available mask can isolate the requested surface. If only the window surround needs work and the tool paints the whole shaft, explain the scope and discuss an appropriate local edit. Store the revised direction with the object through the editor’s journal. Preview alternatives when requested. For critique, discuss one observed strength, one weakness and the smallest edit worth trying. Identify the viewpoint and distinguish rendered evidence from inference.
