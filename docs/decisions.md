# Technical decisions

| Decision and horizon | Reason and tradeoff | When to revisit |
| --- | --- | --- |
| **Now · Generate the registered tower with standalone TypeScript.** | Circular lofts and subtractive cuts produce local voxels offline. The existing Minecraft executor retains dimension checks, receipts, conditional fills and undo. Complete stored repaint receipts let older hillside towers retain their brown finish. | Compare additional execution backends when the geometry is shared by a second build. [Milestone 2](current-milestone.md) |
| **Now · Give common actions a native Fabric menu.** | A rebindable key opens a marker picker and action buttons. The client reads saved marker names and coordinates from the local Studio session and submits actions as addressed player chat. Existing world checks, persistence and provider routing stay with the listener. | Revisit the shared local file when supporting remote worlds or multiple players. [Player controls](collaborate.md) |
| **Now · Retain MCPFabric, WorldEdit and Axiom on one Fabric target.** MCPFabric handles structured access, WorldEdit offers bulk edits and player history, and Axiom supports manual building. | This combination runs in the existing lab. Studio's checked column writes have their own receipts and undo history. | A measured capability gap, such as native push-to-talk input or ghost rendering, can justify a small Fabric addition. [Evaluation](evaluation-report.md) |
| **Now · Keep direct edits and optional previews.** A bounded build request can apply immediately in the authorized lab. | The player removed the mandatory approval step during the chat trial. Preview, cancellation, guarded writes and checked undo serve different purposes. | Introduce additional review modes when the player asks for them or when expanding authorization beyond the current lab. [Chat guide](in-game-building.md) |
| **Now · Keep the agent runtime behind a local interface.** Codex App Server is the default. A mock adapter supports repeatable tests, and a loopback adapter can use an installed Ollama model. | Codex can resume a thread, interrupt a turn and accept an image. Studio persists its own world facts and transcript and enforces edit permissions for every adapter. | Add another agent runtime when the player chooses one. Check its capabilities explicitly. [Provider guide](agent-providers.md) |
| **Now · Use a focused Windows helper for push-to-talk.** | This PC already has desktop speech recognition and synthesis. The helper scopes the held key and audio capture to the authorized Minecraft instance. It avoids adding a mod dependency for this input. | A native Fabric keybinding or a different speech backend becomes appropriate for another platform, Minecraft Controls integration or a richer client HUD. [Voice](voice.md) |
| **Now · Separate world facts from provider session state.** The local editor keeps material parameters, surveyed changes and undo receipts. | A provider thread can refer to a tower, but its transcript is insufficient to decide which blocks are safe to edit. A live survey can operate without a generated recipe. | Extend storage when named markers or additional kinds of object need stable identities. [State](../scripts/studio-state.mjs) · [Survey](../scripts/survey-roof.mjs) |
| **Next milestone · Extract geometry and material operations as they gain callers.** | The current tower and palette are narrow examples. Offline deterministic algorithms and a measured choice of executor support reuse. | Introduce a shared operation for a concrete second use case. Compare fills, WorldEdit and schematics on the relevant workload. [Benchmarks](../benchmarks/README.md) |
| **Long term · Keep artistic guidance and autonomy policies replaceable.** | Artistic skills should express intent. Material algorithms should place the resulting blocks. A provider switch should preserve world plans and personal preferences. | Revisit when the first reusable artistic skill, preference record or alternative provider is exercised. |
| **Speculative · Defer deployment and distribution choices.** | Multiple agents, public distribution and shared style packs have no current acceptance case. | Record a new decision when a real workflow depends on one. |

When a decision changes, record the affected milestone, observed need, tradeoff against the vision, and evidence that would warrant reconsideration.
