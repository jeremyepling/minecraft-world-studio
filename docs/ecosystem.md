# What to reuse

The following are documentation checks on November 24, 2026. Only MCPFabric, WorldEdit and Axiom were selected for installation. Other projects' demonstration results belong to their authors.

| Project | What its published material supports | Consequence for this project |
| --- | --- | --- |
| MCB | Fabric 26.2, an in-game prompt queue with long polling, player-context WorldEdit commands and selection, Litematica ghosts, schematic generation and paste. | Closest small example of a player asking for a preview. Its Claude Code listener is relevant to a Codex adapter. [Repository](https://github.com/Gasased/mcb) |
| Blockwright | RCON editing plus world-file reads. The surface includes slope, walkability, route profiles, terrain-inclusive HTML previews, isometric renders and undo. Large builds can switch to tiled templates. | Reuse survey outputs and inspect-before-commit workflow as design references. RCON and access to world files add deployment requirements. [Repository](https://github.com/ThatHunky/blockwright) |

| Minecraft Builder MCP, 3-03 | Python, local Java server and RCON. Includes generated structures, renders, and datapack examples. | A reference for rendering and exporting authored content. Evidence for persistent semantic architectural layers was insufficient. [Repository](https://github.com/3-03/minecraft-builder-mcp) |
| Ashlar | The supplied URL resolves to CogFlux. | GDPC | Python Editor, WorldSlice, buffered block editing and geometry over the GDMC HTTP interface. ## Native editing and observation

WorldEdit 7.4 documents cuboid selections, masks, weighted patterns, hollow and solid generation, expressions, terrain smoothing, transformations, clipboard operations, schematics and actor-scoped history. Its public Java API exposes actors, local sessions, edit sessions and clipboards. A future companion can create its own edit session and remember it for the appropriate actor. The initial experiment instead exercises the commands already installed. [Manual](https://worldedit.enginehub.org/en/latest/) · [API](https://worldedit.enginehub.org/en/latest/api/)

Axiom documents a WorldEdit selection overlay for `//pos1` and `//pos2`, along with manual selections, brushes, gradients, history and saved views. Inspection of the installed 6.1.5 JAR found the nested `axiomclientapi-unobf.jar` and service entries for RegionProvider, ToolPatherProvider, ToolRegistryService and ToolService. These are Java integration points. An external AI control protocol or shared undo stack across Axiom, Minecraft and WorldEdit was not established. Keep Axiom in the player's hands. [Axiom commands](https://axiomdocs.moulberry.com/advanced/commands.html) · [Manual](https://axiomdocs.moulberry.com/) · [Client API](https://github.com/Moulberry/AxiomClientAPI)

MCPFabric can combine an egocentric scene, a client framebuffer, a remembered chunk map and sampled block states. For a build site, compute column height, water presence and slope from bounded, loaded columns and retain dimension, bounds, sampling time and resolution. Classify logs and leaves separately from walkable ground. A low-resolution explored map cannot support foundation leveling or identify ownership. Sightlines require explicit rays or views. Roads, existing structures, protected regions and future districts need labels or separate data layers. No stock parcel registry, arbitrary cross-section renderer or free camera was identified. For district-scale navigation, BlueMap already renders a browsable 3D map and supports markers. Evaluate the cost and a local-only viewer only when a persistent map is needed. [MCPFabric source review](source-review.md) · [BlueMap](https://bluemap.bluecolored.de/)

## Building references

| Source | A small exercise for a future skill |
| --- | --- |
| BdoubleO100's *Build Texture Breakdown* | Look at how a surface reads from the approach and close up. Compare a quiet wall against a more strongly modeled foundation at the same scale and lighting. [Creator's video](https://www.youtube.com/watch?v=EHRCJM3hiZI) |
| WesterosCraft gradients | Lay out a value progression and examine adjacent blocks together before distributing them on the building. [Gradients](https://westeroscraft.com/docs/building/fundamentals/gradients) |
| WesterosCraft repository world | A separate reference world can hold approved regional walls, roofs, vegetation and palettes with names and viewing points. Use original samples that Jeremy approves. [Repository world](https://westeroscraft.com/docs/building/repository-world) |
| Enginnx | Its building resource index includes value and color theory. Use it to critique warm/cool transitions and focal points in the texture experiment. [Resource index](https://building.enginnx.com/) |
| Axiom | Use the player's color picker, gradient helper and saved views to compare swatches manually. [Documentation](https://axiomdocs.moulberry.com/) |
| GDMC | Review a settlement for adaptation to the map, functionality, narrative and aesthetics. For a road, walk its grade and inspect how it meets water and occupied land. [Judging criteria](https://gendesignmc.wikidot.com/wiki:evaluation) |

A future **agent skill** can teach survey, massing and material review across building tools. A **saved MCPFabric skill** is world-scoped executable JavaScript. Store approved aesthetic rules and palette rationale in the project. Store the reproducible program and its seed alongside each experiment.
